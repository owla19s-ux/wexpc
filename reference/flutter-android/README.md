# Flutter/Android 参考快照

此目录从旧 `apps/wex` 移入，保存 Flutter/Dart 页面、连接器与测试作为迁移参考。它不是 WEXPC 当前桌面应用。旧 README 中“Android 优先”“空态壳”“运行前执行不存在的 tools/bootstrap-flutter.sh”等表述已废弃。

`.github/workflows/rust.yml` 的 Flutter job 仍在此目录做参考代码的 analyze/test；其结果不证明 Tauri/React、Windows UI 或 PC 产品链路已实现。Rust Bridge 目前仍在 `bridge/flutter-rust`，按现有 Cargo workspace 保留。
